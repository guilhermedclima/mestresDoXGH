O que acabou de acontecer

Programar é tradução

Vocês sabiam exatamente o que queriam. O robô é que não adivinha.

Programar é transformar uma intenção óbvia para você numa sequência de passos tão explícita que uma máquina obediente e burra consegue seguir.

A dificuldade quase nunca é matemática. É essa tradução.

Por baixo do capô

O que acontece quando você escreve código

1. Você escreveTexto que um humano lê. Isso é o código.
2. Alguém traduzUm programa converte seu texto para o que a máquina entende.
3. A máquina executaO processador faz, passo a passo, sem pensar.

Só isso. Não tem mágica em nenhuma das três etapas.

A pergunta que todo mundo faz

Por que existem tantas linguagens?

Pelo mesmo motivo que existem várias ferramentas na caixa.

Martelo não é melhor que chave de fenda. Cada linguagem foi criada resolvendo um problema diferente, numa época diferente.

Linguagem é ferramenta, não religião. Quem aprende uma bem, aprende a segunda em semanas.

O mesmo programa

"Olá, mundo" em três linguagens

C# (.NET)

using System;

class Programa {
  static void Main() {
    Console.WriteLine("Olá");
  }
}

JavaScript

console.log("Olá");

// + um arquivo HTML
// pra rodar no navegador

Python

print("Olá")

É isso. O arquivo inteiro.

A escolha

Vamos usar Python

  • Menos cerimônia. Você escreve o que importa e nada além disso.
  • Erros legíveis. Ele te diz a linha e o problema.
  • Zero instalação hoje. Roda no navegador.
  • É a língua da IA. Quando a gente chegar lá, já vamos estar em casa.

Eu trabalho com .NET e JavaScript. Escolhi Python porque é o caminho mais curto entre a sua ideia e o resultado na tela.

Já que todo mundo pergunta

Software normal segue regras que alguém escreveu.

É diferente, é poderoso — e não é mágica. A gente vai chegar lá neste curso.

Mas depois do básico. Sem base, usar IA é só apertar botão e torcer — e você não consegue perceber quando ela erra. E ela erra.

Passo 1

Seu primeiro programa

print("Olá, mundo")

Shift + Enter para rodar.

Para muita gente aqui, essa é a primeira vez que um computador faz algo porque você mandou. Vale comemorar.

Passo 2

Variáveis: caixas com etiqueta

nome = "Guilherme"
idade = 30

print("Meu nome é " + nome)
print("Eu tenho " + str(idade) + " anos")

Você guarda um valor numa caixa, cola uma etiqueta, e depois usa pela etiqueta.

Trocou o que está dentro da caixa? Tudo que usa a etiqueta muda junto.

Passo 3

Agora o programa conversa

nome = input("Qual é o seu nome? ")
print("Prazer, " + nome + "! Bem-vindo aos Mestres do XGH.")

input para e espera você digitar.

Deixou de ser um texto fixo. Virou um programa que reage.

Sua vez · 10 min

Cartão de apresentação

Faça um programa que mostra:

  • Seu nome
  • Sua cidade
  • Uma coisa que você quer conseguir construir

Travou? Levanta a mão. É pra travar mesmo.

Passo 4

O programa decide

idade = int(input("Qual sua idade? "))

if idade >= 18:
    print("Pode tirar habilitação")
else:
    print("Ainda não pode")

Repare em duas coisas: os : no fim da linha, e o espaço antes do print.

Em Python o espaço não é enfeite. É ele que diz o que está dentro do quê.

Como ler um erro

Vermelho é endereço, não bronca

  File "<stdin>", line 4
    print("Pode tirar habilitação")
    ^
IndentationError: expected an indented block
after 'if' statement on line 3
  • A última linha = que tipo de problema é
  • O número = onde ir olhar
  • O texto = o que ele esperava e não achou

Quem aprende a ler erro vira programador.

Quem entra em pânico e apaga tudo, não.
