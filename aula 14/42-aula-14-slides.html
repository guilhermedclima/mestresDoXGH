git init cria uma pasta

Initialized empty Git repository in

O repositório é uma pasta escondida .git dentro do projeto. Sem conta, sem internet.

Apagou a pasta .git? Acabou o histórico.

Untracked. O git não versiona nada sozinho — só o que você mandar.

git add · escolher o que entra

Em terminal, silêncio é bom sinal

$ git add organiza.py
(sem saída)

$ git status --short
A  organiza.py
??o git não conhece
Anovo, já preparado
_Mmodificado, não preparado
M_modificado e preparado

git add . adiciona tudo. É o que todo mundo usa — e é por isso que todo mundo um dia commita o que não devia.

git commit · fechar o pacote

O hash é o nome do commit

$ git commit -m "organizador move arquivo para subpasta
                 por extensao"
[main (root-commit) cbee89e] organizador move arquivo...
 1 file changed, 13 insertions(+)

$ git log --oneline
cbee89e organizador move arquivo para subpasta por extensao

Sete caracteres do começo já bastam para você se referir a ele.

Commit é um ponto de retorno.

O resto é coragem.

Como ler

Uma linha saiu, quatro entraram

  • --- é como estava · +++ é como está
  • @@ -1,11 +1,14 @@ — eram 11 linhas, agora são 14
  • − saiu · + entrou · sem nada na frente: só contexto

Rode git diff antes de todo git add.

É a última chance de ver aquele print("teste 123") que ficou no código.
E a mensagem do commit não repete o diff: ela diz para que o modo simulação existe.

Depois de algumas execuções

Qual desses três é o seu código?

$ git status --short
?? .venv/
?? __pycache__/
?? organiza.log

Nenhum.

Cache que o Python refaz · o venv que a Aula 11 prometeu · o log da Aula 13.

.gitignore · uma regra por linha

E eles somem do status

O arquivo

__pycache__/
.venv/
*.log

O resultado

$ git status --short
?? .gitignore

O .gitignore entra no commit: a regra também é parte do projeto.

Ignorar é dizer ao git para não olhar — não ao computador para apagar.

A regra

Gerado, baixado,
pesado ou secreto:
não vai para o git

Segura a última palavra. Depois do café.

O que fazer de verdade · a ordem importa

Chave vazada não tem conserto. Tem substituição.

  • Revogue a chave no painel do provedor. Só isso resolve

  • Commite o .gitignore e um config.exemplo.py sem segredo
  • Só então pense em reescrever o histórico — é cirurgia, e não desfaz quem já copiou

git ≠ GitHub

gito programa que guarda o histórico, no seu computador
GitHubum site que hospeda repositórios git
git remote add origin https://github.com/SEU-USUARIO/organizador.git
git push -u origin main

origin é só um apelido para o endereço.
-u origin main liga os dois — da segunda vez em diante é só git push.

Vai acontecer com vocês hoje

A senha que não é senha

O GitHub não aceita mais a senha da conta no git push.

Settings → Developer settings → Personal access tokens
→ Tokens (classic) → Generate new token → escopo repo

Usuário é o seu login. Senha é o token.

E esse token é exatamente o tipo de coisa do bloco anterior: nunca em arquivo, nunca em commit, nunca no grupo.
