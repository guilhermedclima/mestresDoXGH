Hoje a gente descobre por que a tarefa de casa quebrou.

A tarefa de casa

Por que deu 22?

a = input("Primeiro número: ")
b = input("Segundo número: ")

print(a + b)

Digitei 2 e 2. Apareceu 22.

A explicação

input() sempre devolve texto

Sempre. Mesmo quando você digita um número.

E somar dois textos em Python não soma. Gruda.

print("casa" + "grande")   # casagrande
print("2" + "2")           # 22

O computador não se confundiu.

Ele fez exatamente o que vocês pediram.

De novo.

O conserto

Uma palavra resolve

a = int(input("Primeiro número: "))
b = int(input("Segundo número: "))

print(a + b)   # 4 🎉

int() pega um texto que parece número e transforma em número de verdade.

A ideia central
de hoje

O computador não guarda só o valor.

Ele guarda o valor e o que aquilo é.

E o que ele acha que aquilo é muda o que o + faz.

O básico do básico

Os quatro tipos

str"Guilherme"Texto. Sempre entre aspas.
int30Número inteiro.
float1.75Número com casa decimal.
boolTrue / FalseVerdadeiro ou falso. Só isso.
Sua ferramenta de investigação

type() — na dúvida, pergunte

print(type(nome))     # <class 'str'>
print(type(idade))    # <class 'int'>
print(type(altura))   # <class 'float'>

Deu erro estranho? Antes de sofrer, roda type().
Metade dos bugs de iniciante é o tipo não ser o que você achava.

Pega quase todo mundo

Três detalhes traiçoeiros

  • "30" e 30 não são a mesma coisa. O primeiro é texto que parece número.
  • O separador decimal é ponto, não vírgula. 1,75 não é número.
  • True e False com maiúscula e sem aspas. Com aspas viram texto.

Trocando de tipo

Conversão

int("42")     # 42
float("3.14") # 3.14
str(7)        # "7"
int(x)vira número inteiro
float(x)vira número decimal
str(x)vira texto
Cuidado com esse

int() corta. Não arredonda.

int(9.99)   → 9

Não é 10.

Ele joga fora tudo depois do ponto.
É o tipo de detalhe que vira bug silencioso três semanas depois.

Montando texto

Primeiro, o jeito chato

print("Oi, " + nome + "! Você tem " + str(idade) + " anos.")

Conta quantos +. Conta quantos str().

Agora imagina isso com seis variáveis.

O jeito bom

f-string

print(f"Oi, {nome}! Você tem {idade} anos.")

O f antes das aspas libera as chaves. O que estiver dentro de {} o Python calcula e coloca ali.

print(f"Ano que vem você faz {idade + 1}.")

Sem +. Sem str(). A partir de hoje é o padrão da turma.

Bônus útil

Casas decimais

preco = 19.9

print(f"{preco}")        # 19.9
print(f"R$ {preco:.2f}")  # R$ 19.90

:.2f = mostra com 2 casas decimais.

Sempre que tiver dinheiro na tela, use.

A pergunta

Vocês passaram a aula convertendo texto em número.

O ChatGPT recebe texto.

Mas por dentro, computador só sabe fazer conta.

Como é que texto vira conta?

Converte.

Exatamente como vocês fizeram hoje às 10h45.

Passo 1

Toda letra já é um número por baixo

print(ord("a"))   # 97
print(ord("b"))   # 98
print(ord("A"))   # 65

Isso ainda não é IA — é só a tabela de caracteres, existe desde sempre.

Mas mostra que a ponte texto → número é concreta.

Passo 2

Frase entra. Lista de números sai.

frase = "o gato subiu no telhado"
pedacos = frase.split()

# ['o', 'gato', 'subiu', 'no', 'telhado']
# →  [1, 2, 3, 4, 5]

Não se preocupem com o código — parte é da aula 5.
Olhem só o que entrou e o que saiu.

Guardem estas três

O que sustenta o resto do curso

  • Todo modelo de IA só come número. Texto, imagem e som viram número antes de entrar. Sem exceção.
  • Isso tem nome: tokenização. Vocês fazem de verdade na aula 5.
  • Num modelo real o número não é 1, 2, 3. É uma lista de centenas de números que carrega significado, aprendido sozinho lendo bilhões de frases. Chama embedding.

Quando alguém disser que IA é mágica:

é conta.

Muita conta, com números que alguém precisou converter antes.
