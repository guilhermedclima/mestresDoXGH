💊 Pílula de IA

Um classificador é um if
que ninguém escreveu

Hoje vocês aprenderam a decidir.
Detector de spam decide. Vamos fazer um.

Etapa 1

Vocês já sabem fazer isso

def eh_spam(mensagem):
    suspeitas = ["promocao", "gratis", "clique", "premio"]
    for palavra in suspeitas:
        if palavra in mensagem:
            return True
    return False

def e for são das aulas 6 e 4. Olhem só o if no meio — ele é o classificador inteiro.

Etapa 2

Agora quebrem o próprio classificador

eh_spam("o curso e gratis para os alunos")

→ True  ❌

Uma mensagem honesta virou spam.

Você adiciona uma exceção.

Aí quebra outra coisa.

A lista de regras nunca acaba.

Etapa 3

E se o computador escrevesse as regras sozinho?

vetor = CountVectorizer()
X = vetor.fit_transform(mensagens)
modelo = MultinomialNB().fit(X, rotulos)

Três linhas. 16 exemplos marcados como spam ou normal.

Zero regras escritas por mim.

Frases que ele nunca viu

O resultado

spam    (100%)  <- promocao gratis clique aqui
normal   (88%)  <- vamos almocar amanha
spam     (99%)  <- clique no link e ganhe dinheiro
normal   (94%)  <- segue o relatorio em anexo

Nenhuma regra. Nenhuma lista de palavras suspeitas.
Só 16 exemplos com a resposta certa.

Etapa 4 · não pulem essa

O modelo também erra

spam    (61%)  <- o curso e gratis para os alunos
spam    (55%)  <- voce pode me mandar o link da reuniao

Errou igual à regra manual. Mas olhem a confiança.

Ele está em cima do muro — e sabe disso.
Minha regra dizia True com certeza absoluta.

Um modelo que sabe que está inseguro

é mais útil que uma regra
convicta e errada.

Em sistema sério, caso com confiança baixa vai para um humano olhar.

Etapa 5 · o desfecho

spam    (96%)  <- promocao gratis clique aqui

Não escrevi nenhuma regra nova.

Dei mais 8 exemplos.

Guardem estas três

O que fica da pílula de hoje

  • O if continua lá dentro. O modelo decide comparando números com limiares — só que você não escreveu os limiares.
  • Dado vale mais que código em IA. Corrigir modelo é conseguir mais exemplo, não escrever mais regra.
  • O modelo diz o quanto está inseguro. Aquele 61% é informação, não defeito.
