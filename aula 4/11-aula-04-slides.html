while

for é para quando você sabe quantas voltas.

E quando você não sabe?

Enquanto a condição for verdadeira, faça

Contagem regressiva

n = 5
while n > 0:
    print(n)
    n = n - 1

print("Fogo!")
Se faltar uma, quebra

As três partes de todo while

  • Antes: algo que a condição consiga olhar — n = 5
  • A condição: a pergunta de sim ou não — n > 0
  • Dentro: algo que muda a condição — n = n - 1

A terceira é a que todo mundo esquece.

Os 200 elif,
resolvidos

A pergunta tem duas respostas.

Qual serve depende das faixas.

Resposta 1

Se as faixas seguem uma regra,
você não decide — você calcula

for valor in [850, 2400, 4200, 7300]:
    faixa = valor // 1000
    print(f"R$ {valor} → faixa {faixa}")

R$ 850 → faixa 0
R$ 2400 → faixa 2
R$ 4200 → faixa 4
R$ 7300 → faixa 7

// divide e joga o resto fora. Zero if.

Resposta 2

Se as faixas são arbitrárias,
você guarda a tabela e percorre

limites = [1000, 3000, 5000, 10000]

for valor in [850, 2400, 4200, 7300]:
    faixa = "até 1000"
    for limite in limites:
        if valor >= limite:
            faixa = f"acima de {limite}"

Um for dentro de outro, e o if lá no fundo.

Para ter 200 faixas,
a lista cresce.

O código não muda
uma linha.

É a diferença entre um programa que você escreve
e um que você alimenta.

O que fica da pílula de hoje

  • Treinar não é mágica. É um for que chuta, mede o erro e corrige.
