A regra mora num lugar só

Parâmetro com valor padrão

def situacao(nota, corte=7):
    if nota >= corte:
        return "aprovado"
    else:
        return "reprovado"

situacao(8.5)            # aprovado
situacao(6.0)            # reprovado
situacao(6.0, corte=6)   # aprovado

Função não é para escrever menos.

É para ter um lugar só onde mexer.

💊 Pílula de IA

Um modelo
é uma função

Etapa 1 · a caixa

Entra uma coisa, sai outra

def dobro(x):
    return x * 2

dobro(21)   # 42

Você não precisa saber o que tem dentro para usar.

Etapa 2 · lembram do 1.681?

O modelo da Aula 4 é literalmente isto

def prever_nota(horas):
    return 1.681 * horas

prever_nota(2)     # 3.362
prever_nota(3.5)   # 5.8835

É isso. É o modelo inteiro. Uma linha.

Etapa 3 · o coração da pílula

Quem escreveu o corpo?

def dobro(x):
    return x * 2

o 2 fui EU que escrevi

def prever_nota(h):
    return 1.681 * h

o 1.681 ninguém escreveu

Ele saiu de 50 voltas de um for medindo erro.

A chamada é idêntica. Só o corpo mudou.

Antes e depois do treino

2h -> chute 1.0 | treinado 3.4 | real  4
4h -> chute 2.0 | treinado 6.7 | real  7
6h -> chute 3.0 | treinado 10.1 | real 10

Treinar um modelo é escrever o corpo de uma função sem digitar o corpo dela.

Você define o formato.
Os dados escolhem os números.

Etapa 4 · e ele erra com cara de certeza

Quantas horas para tirar 10?

prever_nota(7)

→ 11.767

Nota acima de 10.

Ninguém contou para ele que o máximo é 10.
Os dados dele iam até 6 horas.

Isso se chama
extrapolar

Uma das formas mais comuns de IA
falar bobagem com confiança total.

Um modelo não sabe que não sabe.

Guardem estas três

O que fica da pílula de hoje

  • Um modelo é uma função. Entra dado, sai resposta.
  • A sua função vocês escreveram; a do modelo os dados escreveram. Só isso muda.
  • Fora do que ele viu, ele inventa — com a mesma cara de certeza.
