A ferramenta de hoje

Dicionário: cada valor tem um nome

aluno = {
    "nome": "Ana",
    "nota": 8.5,
    "faltas": 2
}

aluno["nome"]    # Ana
aluno["nota"]    # 8.5
A diferença que muda tudo

O que você precisa saber

Como pedePrecisa saber

O valor está amarrado ao nome,
não à posição.

Vocabulário

Chave e valor

"nota": 8.5
  │      └── valor (value)

Mudar e criar

Atribuir numa chave nova cria a chave

aluno["nota"] = 9.0              # muda
aluno["email"] = "ana@..."      # CRIA

len(aluno)          # 4
"nota" in aluno     # True

Numa lista de 3 itens, notas[10] = 5 dá IndexError.
Aqui o dicionário só cresce.

💥 Quebrando de propósito nº 1

Uma chave que não existe

aluno["telefone"]

KeyError: 'telefone'

KeyError é o IndexError do dicionário.

Para perguntar sem quebrar

.get()

aluno.get("telefone")
# None

aluno.get("telefone", "não informado")
# não informado

Use quando não tem certeza de que a chave está lá.
E isso é a regra quando o dado vem de fora.

💥 Quebrando de propósito nº 2

Dicionário não tem índice

aluno[0]

KeyError: 0

O [0] não é "o primeiro item" — é uma tentativa de buscar a chave 0.

Regra de leitura, para sempre

Viu [ ]? Olhe o que está dentro.

númeroé posição → é uma LISTA
textoé nome → é um DICIONÁRIO
Percorrer

O for sozinho passa pelas chaves

for chave in aluno:
    print(chave, "->", aluno[chave])

Não pelos valores. Isso pega gente.

O que vocês mais vão usar

.items() entrega os dois

for chave, valor in aluno.items():
    print(f"{chave} = {valor}")

Repare: dois nomes antes do in.
Ele entrega duas variáveis por volta.

Lista de dicionários

É o formato de quase todo dado
que vocês vão encontrar na vida.

Uma lista. Cada item, um dicionário.

A turma, de verdade

turma = [
    {"nome": "Ana",   "nota": 8.5, "faltas": 2},
    {"nome": "Bruno", "nota": 4.0, "faltas": 7},
    {"nome": "Carla", "nota": 9.5, "faltas": 0},
]

for a in turma:
    print(a["nome"], a["nota"])
Cuidado com a aspa

Fora dupla, dentro simples

f"{a['nome']} tirou {a['nota']}"
  ▲    ▲
  │    └── simples aqui dentro
  └─────── dupla aqui fora

Mesma aspa dos dois lados e o Python se perde.

E as funções da Aula 6 continuam servindo

Nada foi jogado fora

def media_da_turma(turma):
    soma = 0
    for a in turma:
        soma += a["nota"]
    return soma / len(turma)

# média: 7.33
# aprovados: ['Ana', 'Carla']
O teste que fecha a manhã

Embaralhem a turma inteira

random.shuffle(turma)

Bruno  4.0
Carla  9.5
Ana    8.5

A ordem mudou. As notas foram junto.

Era isso que estava quebrado às dez da manhã.

A lista guarda ordem.
O dicionário guarda nome.

JSON

Um dicionário só existe dentro do Python.

Para mandar pela internet ou salvar num arquivo,
ele precisa virar texto.

dict → texto

json.dumps

aluno = {"nome": "Ana", "aprovado": True}
json.dumps(aluno)

{"nome": "Ana", "aprovado": true}
<class 'str'>

Parece igual, mas é uma string.
E o True virou true, minúsculo.

Escrevam no caderno 
dict → json.dumps → texto → json.loads → dict

dumps escreve. loads lê.

O s no fim é de string.

💥 Quebrando de propósito nº 3

Aspas simples não são JSON

json.loads("{'nome': 'Ana'}")

JSONDecodeError: Expecting property
name enclosed in double quotes

Quase sempre a causa é a mesma: alguém colou um dicionário Python onde o programa esperava um JSON.

Guardem estas três

O que fica da pílula de hoje

  • API de IA é JSON entrando e JSON saindo. Vocês já sabem ler e escrever os dois.
  • Aquela linha assustadora é só chave, índice, chave, chave.
  • O modelo não tem memória. O histórico é uma lista de dicionários que vocês reenviam.
